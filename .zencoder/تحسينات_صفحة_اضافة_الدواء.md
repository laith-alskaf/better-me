```
┌─────────────────────────┐
│  إضافة دواء             │
```

## 🎨 التفاصيل التقنية

### Shadows المستخدمة:
```dart
// Shadow رئيسي (أسود)
BoxShadow(
  color: Colors.black.withValues(alpha: 0.08),
  blurRadius: 10,
  offset: Offset(0, 4),
)

// Shadow ملون (حسب نوع الحقل)
BoxShadow(
  color: iconColor.withValues(alpha: 0.05),
  blurRadius: 20,
  offset: Offset(0, 8),
  spreadRadius: -4,
)
```

### الألوان المستخدمة:
- 🔵 **Primary (أزرق)**: اسم الدواء، Header
- 🟠 **Orange (برتقالي)**: الجرعة
- 💊 **Dynamic**: نوع الدواء (يتغير حسب النوع)
- ⏰ **Blue**: التكرار
