## 🚀 التحسينات التفصيلية

### 1. حقول الإدخال 🔵🟠

**قبل**:
```
[                    ] ← بدون shadow
```

**بعد**:
```
🔵 [اسم الدواء      ] 📦 ← shadow + icon أزرق
🟠 [500             ] mg 📦 ← shadow + icon برتقالي + وحدة mg
```

**المزايا**:
- Shadow مزدوج (أسود + ملون)
- Icon ملون داخل مربع
- وحدة "mg" تظهر تلقائياً للجرعة
- Border يتحول للون مميز عند الكتابة
